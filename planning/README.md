# Planning

This folder holds two kinds of plans:

- **Upstream's original plans** (February 2026), by Adam Zebrowski in [azebro/pytap](https://github.com/azebro/pytap/tree/main/planning), kept unchanged as his record: [`feature1.md`](feature1.md) (per-optimizer energy), [`feature2.md`](feature2.md) (string and installation totals), [`feature3.md`](feature3.md) (performance), [`feature5.md`](feature5.md) (diagnostics and readings counter) and [`future_considerations.md`](future_considerations.md) (his roadmap).
- **This fork's roadmap:** [`fork_roadmap.md`](fork_roadmap.md). It goes through upstream's roadmap item by item, says where the fork follows it and where it differs, and adds the fork's own plans.

The fork's current design is in [`docs/architecture.md`](../docs/architecture.md), and how it got there, phase by phase, in [`docs/implementation.md`](../docs/implementation.md).
